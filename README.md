# User Activity Tracking System

A JavaScript-based project designed to track, analyze, and monitor user activities.

## Features

- Track user activities
- Analyze user behavior
- Calculate user statistics
- Detect unusual activities
- Display activity timelines
- Simulate live user activities
- Process activity data
- Monitor user sessions
- Complete bonus challenge

## Technologies Used

- HTML
- CSS
- JavaScript

## JavaScript Concepts Used

- Arrays and Objects
- Map
- Loops and Conditions
- Array Methods
- Date
- Spread Operator
- Functions

## Project Purpose

This project helps track user activities, analyze user behavior, identify unusual activities, and monitor user sessions using JavaScript.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
